# 查看器控件（ViewerWidget）

## 1. 目的
只读 Markdown 视图：加载、虚拟化滚动、目录跳转、选区/复制、链接、查找，替代旧 `PreviewWidget + EditorWidget + ScrollSync`。

## 2. 行为契约
- **[INV-VIEW-NO-LAYOUT-IN-PAINT]** `paintEvent` 只读已就绪的布局缓存；解析、布局、`ScrollModel` 写入、滚动条同步一律在 `prepare()`（滚动/缩放/数据到达/图片就绪后同步或排队调用）。`m_inPaint` / `m_inPrepare` 双重保护防重入。
- **[INV-VIEW-ANCHOR]** 滚动位置以 `ScrollModel` 锚点为准；滚动条值只由锚点推导（`m_syncing` 屏蔽反向信号）。
- **[INV-VIEW-CACHE-BOUNDED]** 布局缓存 ≤ 160 个 chunk，超限按与锚点的距离从远到近淘汰（可视 chunk 豁免）。
- **[INV-SEL-CHUNK-LOCAL]** 选区端点 = (chunk, 块内字符序号)；字符计数规则与 `PreviewPainter::countBlockChars` / `extractBlockText` 同源（改一处必须同改）。
- **[INV-VIEW-JUMP-EXACT]** 跳转到源行：目标 chunk 布局后取包含该行的顶层块 Y 作为锚点偏移，零估计误差；目标行尚未被扫描到时挂起，待后续批次到达后执行。
- **[INV-VIEW-RELOAD-KEEP]** `reload()` 记录 `topSourceLine()`，重新加载完成后跳回（不高亮）。
- 宽度变化：40ms 去抖后失效全部布局（锚点保持）；仅高度变化只重新计算可视范围。
- 滚轮：像素级事件直接滚动；整格滚轮累积到「剩余量」并以指数衰减逼近，反向立即清零；一格 = 3 行。
- **[INV-VIEW-LINK-CTRL-CLICK]** Ctrl+左键点击链接文字发出 `linkClicked(url)`，由主窗口交给系统浏览器（http/https/mailto）或在新标签页打开相对路径的 .md；不带 Ctrl 的点击只做选区。解析器启用 GFM 自动链接，裸 URL / 邮箱 / `<url>` 都是链接。
- 错误态（二进制/过大/读取失败）居中显示错误文案；加载中显示「Loading…」。

## 7. 验收条件
T1 加载得到目录/行数；T2 缺失文件报错；T3 目录跳转标题落在顶部；T4 End 对齐末尾；T5 全选复制 == 整篇文本；T6/T7/T8 **分块渲染文本 == 整篇渲染文本**（生成文档、14 类切块陷阱、强切围栏）；T9/T10 查找；T11 重载保持位置；T12 宽度变化锚点不变；T13 缓存有界；T14 空文件/单行；T18 Ctrl+点击链接（含裸 URL、尖括号自动链接）。
