# 分块扫描（ChunkScanner）

## 1. 目的
把任意大小的 UTF-8 Markdown 文本，用一次线性扫描切成可**独立解析、独立布局**的 chunk，并同时产出目录（标题）索引，使「打开 → 首屏」与文件大小无关。

## 2. 输入 / 输出
- 输入：稳定的字节缓冲 + 当前可用字节数（可多次增量调用）+ final 标志。
- 输出：`Chunk[]`（字节区间、起始行、行数、前导合成围栏）、`HeadingEntry[]`、引用式链接定义文本。

## 3. 行为契约（不变量）
- **[INV-SCAN-COVER]** chunk 按顺序首尾相接覆盖 [bodyStart, size)（bodyStart 为 BOM 后），不重叠不遗漏；`Σ lineCount == 文件物理行数`（续片 lineCount=0）。
- **[INV-SCAN-SAFE-CUT]** 仅在「空行之后、下一行缩进 0、不是列表项」处切块；围栏代码块、HTML 原始块（`<!--` `<script` `<pre` `<style` `<textarea` `<?` `<![CDATA[`）、frontmatter 内部不切；列表（含松散列表）内部不切。
- **[INV-SCAN-HARD-CAP]** 单 chunk 超过 hardLines(600)/hardBytes(64KB)（围栏内部 fenceHardLines=300）：围栏内部强切并为续块合成围栏头（`prologue`），闭合围栏由 `assemble()` 补；列表可在顶层项之间切；达到 2 倍上限时在任意行边界切（可能破坏表格，降级可接受）；单行超过 8KB 按 UTF-8 字符边界切片。
- **[INV-SCAN-TOC]** 标题索引包含围栏/HTML 原始块/frontmatter 之外的 ATX 标题与 setext 标题；`chunkIndex` 指向包含该标题行的 chunk。
- **[INV-SCAN-INCREMENTAL]** 分多次喂入（只处理完整行）与一次性喂入得到完全相同的结果。
- **[INV-SCAN-REFDEF]** 全文引用式链接定义附加到每个 chunk 解析输入末尾，使跨 chunk 的 `[x][id]` 正常解析。

## 4. 接口
见 `src/viewer/ChunkScanner.h`。

## 5. 核心算法
逐行（memchr 找换行）状态机：frontmatter → 围栏 → HTML 原始块 → 普通行（切块判定/围栏开启/标题/setext/引用定义）。

## 6. 性能预算
扫描速度 ≥ 400MB/s（Release），50MB 文件 ≤ 150ms 量级（由 worker 线程承担，不阻塞 UI）。

## 7. 验收条件（T 编号）
- T1 空文件/只有空行；T2 单行无换行；T3 CRLF；T4 BOM；T5 围栏内含空行与 `#` 不被当标题且不切；T6 松散列表不被切开；T7 ATX/setext 标题索引；T8 引用定义收集并附加；T9 frontmatter 不被切且其后 `---` 视为分隔线；T10 围栏强切合成围栏头；T11 超长行切片在 UTF-8 边界；T12 增量喂入与一次性一致；T13 覆盖/行数不变量；T14 HTML 注释内空行不切；T15 缩进代码块不切；T16 围栏未闭合；T17 标题 snake_case 保留下划线。

## 8. 已知降级（2026-11-02 病态输入探测结论）
- 表格被 2 倍上限强切后，后续 chunk 没有表头行，退化为普通文本（超大表格 ≥1200 行才会出现）。
- 无换行的超长行在词中间被切成多个段落。
- 引用式链接定义只收录前 2000 条（每个 chunk 都会附加，数量过多会拖慢解析）。
- 目录条目最多 20 万项（再多的标题正文照常渲染，只是不进目录面板）。
