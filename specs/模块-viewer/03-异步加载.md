# 异步加载（DocumentLoader）

## 1. 目的
文件读取与扫描全部在专用 worker 线程完成，UI 线程只消费增量批次；首屏时间与文件大小无关。

## 2. 行为契约
- **[INV-LOAD-NONBLOCKING]** UI 线程不做任何文件 IO 与扫描；首批（≈64KB）扫描完成即发布。
- **[INV-LOAD-WATERMARK]** 源缓冲一次预分配（文件大小），worker 渐进填充；每个批次带「水位线」，UI 只能读水位线以下。
- **[INV-LOAD-GEN]** 每次 `start()` 先 `cancel()` 旧任务（置取消标志、断开通知，不等待）；旧任务结果不会进入新加载。
- **[INV-LOAD-NOLOCK-FILE]** 读完即关闭文件句柄，不使用内存映射，保证外部编辑器可原子保存（Windows 不被文件锁拒绝）。
- **[INV-LOAD-ENCODING]** 前 64KB 非合法 UTF-8 或带 UTF-16 BOM 时整体转码为 UTF-8（GB18030 / UTF-16）；前 8KB 含 NUL 视为二进制并拒绝；超过 1GB 拒绝。
- **[INV-LOAD-NOPOOL]** 使用专用 QThread，禁止使用全局 QThreadPool（进程退出时线程池析构会与已终止的工作线程死锁，2026-11-02 实测：测试进程退出后挂起）。

## 7. 验收条件
T1 异步=同步结果且分批；T2 空文件；T3 缺失文件报错；T4 二进制拒绝；T5 GBK 转码；T6 UTF-16 BOM；T7 中途销毁安全；T8 立即重启丢弃旧结果；T9 20MB 首批 <1MB 水位线。
