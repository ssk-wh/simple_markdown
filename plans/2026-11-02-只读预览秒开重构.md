# 只读预览秒开重构（去编辑器 + 分块增量解析 + 虚拟化滚动）

## 背景
用户反馈打开慢。目标：秒级打开、滚动丝滑、点击目录迅速定位、支持大文件；允许去掉编辑功能，仅保留预览；允许重做架构。
截止：2026-11-03 02:00 前保存进展并停止。

## 基线测量（2026-11-02，Release/MSVC，本机）
| 场景 | 数据 |
|---|---|
| 1MB(2.6万行) 完整启动到窗口可见 | **17.5s**（restoreSession 15.6s，主线程一次 paint 阻塞 16s） |
| 空窗口冷启动到 MainWindow 创建完成 | ~1.4–1.9s（翻译加载 ~200–350ms，FolderPanel+splitter ~500ms，QApplication 属性/图标 ~200ms，菜单 ~100ms） |
| cmark 解析 + AST 转换 | 1MB 66ms；10MB 746ms |
| PreviewLayout 全量布局 | 1MB 312ms；10MB 3128ms（线性，50MB≈15s） |
| PreviewLayout 视口模式 | 首次 ~300ms（字体度量预热），10MB 379ms（粗估全部块） |
结论：主要瓶颈 = 编辑器（Document/PieceTable/EditorLayout/高亮）的同步全量处理 + 预览全量 AST/布局；与「去掉编辑」目标一致。

## 技术栈决策
保持 C++/Qt5 Widgets 自绘（不换 WebView/Electron/Rust）：
- 产品愿景 INV-4（不依赖 WebEngine）、INV-1（冷启动 <0.5s、空载内存 <30MB）与之冲突；Chromium 系冷启动 ≥ 300ms 且内存 ≥ 100MB。
- 基线显示瓶颈不在 Qt 绘制，而在「同步全量」的处理流水线；换栈不解决这个问题，重写 1.7 万行代码又无法在期限内回归。
- 重用资产：cmark-gfm 解析、PreviewLayout/PreviewPainter 的单块布局与绘制、Theme、ImageCache、TocPanel。

## 设计 v1（待评审）

### 1. 总体：去编辑器 + 分块（Chunk）+ 虚拟化
```
文件 ──(worker线程: 读文件 + 扫描)──► ChunkTable（边界/行号/高度估计） + TocIndex（标题）
                                        │（按需，主线程，毫秒级）
可视 chunk ─► cmark 解析(单 chunk) ─► PreviewLayout 单块布局 ─► LayoutBlock 缓存(LRU)
                                        │
ViewerWidget(QAbstractScrollArea) ─► 只绘制可视 chunk，滚动条 = chunk 高度前缀和
```
### 2. 模块
- `viewer/ChunkScanner`：线性扫描 UTF-8 字节，识别围栏代码块/frontmatter，在「空行 + 下一行顶格非列表项」处切块（目标 ~40 行/块，超大围栏代码按行数强切，保证单块布局成本上界）；同时产出标题索引（ATX + setext，围栏外）与引用式链接定义（附加到每个 chunk 解析输入末尾）。
- `viewer/ChunkTable`：chunk 数组 {byteStart,byteEnd,lineStart,lineEnd,estH,realH,state}；高度前缀和用 Fenwick 树（O(log n) 更新/查询）。估高 = 行数 × 动态校准系数（已测量 chunk 的 realH/行数滑动均值，按 kind 分类）。
- `viewer/ViewerWidget`：滚动位置用「锚点」(chunkIndex, offsetInChunk) 表示；chunk 高度从估计变为实测时，若位于锚点之上则同步补偿滚动条值，视觉内容不跳动。滚动条值 = prefix(anchor.chunk)+offset，用户拖动滚动条时反查锚点。
- 选区/复制：选区 = (chunk, 块内字符序号) 二元组两端；每个 chunk 独立走 PreviewPainter（字符计数块内从 0 开始）；复制时对区间内 chunk 按需布局取纯文本。
- 查找：worker 线程在源文本上做子串搜索得到候选 chunk 列表；上/下一个命中 = 切到候选 chunk 并在该 chunk 渲染文本里高亮；渲染文本无命中则跳过候选。
- 目录：TocIndex 来自扫描器（不依赖布局）；点击 → 锚点直达目标 chunk 顶部（零估计误差），目标 chunk 之上的高度逐步精算时锚点补偿，因此「秒跳」且位置准确。
- 文件加载：worker 线程 QFile::readAll（不 mmap，避免 Windows 下锁文件使外部编辑器保存失败）；先发布首批 chunk（扫描 ≥64KB 后立刻通知 UI），其余边扫边追加；首屏时间与文件大小无关。
- 编码：沿用现有 BOM/GBK 检测；非 UTF-8 一次性转码为 UTF-8 缓冲。
- 内存：仅保留可视 ±3 屏的 LayoutBlock（LRU 上限 256 chunk）；AST 布局后即丢弃。

### 3. 应用层
- 删除 EditorWidget/Document 编辑路径/SyntaxHighlighter/ScrollSync/编辑菜单；Tab = ViewerWidget；保留：多 Tab、目录面板、文件夹面板、主题、最近文件、会话恢复、外部修改检测（改为「已更新，重新加载」）、查找、缩放、链接点击、图片。
- 启动：窗口先显示（延后构造 FolderPanel/菜单中非必需部分、延迟加载翻译以外的重对象）；会话恢复只加载当前 tab，其余懒加载。

### 4. 性能预算（验收）
| 指标 | 目标 |
|---|---|
| 窗口可见到首屏内容（任意大小文件，含 50MB） | ≤ 400ms（冷启动整体 ≤ 1s） |
| 滚动（滚轮/拖滚动条/PageDown）帧耗时 | P95 ≤ 8ms，P99 ≤ 16ms |

## 评审记录

### 第 1 轮（性能架构师 / QA / 稳定性+产品）→ 设计 v2 修订
采纳项（对设计 v1 的修改）：
1. **切块规则保守化**：仅在「空行之后、下一行缩进 0、且不是列表项/缩进代码/HTML 多行块内部」处切块；`<!--`/`<script`/`<pre`/`<style` 开启的 HTML 块在闭合前不切；围栏内不切；列表（含松散列表）内不切。**硬上限强切**（单块 >2000 行或 >256KB）：①列表在顶层项之间切；②围栏代码在内部切，续块合成围栏头（`lineBias` 修正行号）；③超长单行按 UTF-8 边界按字节切。引用式链接定义（`[x]: url`）全文预扫描后附加到每个 chunk 解析输入末尾。
2. **布局入口无状态化**：给 `PreviewLayout` 新增 `layoutChunk(const AstNode&, width)`，不触碰 `m_root`/映射缓存；`PreviewPainter` 每次绘制 chunk 前重置字符计数与 textSegments，由 Viewer 汇总（避免 reuse 串号，即反模式 B）。
3. **滚动数学**：滚动条值 = 前缀和 / scale（总高 >2^30 时缩放）；估高系数由首批实测样本动态校准；宽度/字号/主题变化 → 全部 realH 失效，Fenwick 重建（O(n)），锚点 (chunk, offset) 保持不变；跳转只设锚点，不追求滚动条值精确，滚动条以平滑为准。
4. **绘制重入铁律**：布局、高度回写、`setValue` 一律在 `prepareVisible()`（滚动/缩放/数据到达后同步调用，非 paintEvent）里完成；`paintEvent` 只读已就绪的缓存，缺失的 chunk 画骨架占位。
5. **首屏**：窗口先显示 + 骨架/加载提示；字体度量预热单独测量并优化；文件读取+扫描在 worker，首批（≥64KB）即发布。
6. **稳定性**：worker 带 generation 令牌，Tab 关闭/重新加载时取消并 `wait`；文件上限 1GB（超限提示）；前 8KB 含 NUL 视为二进制拒绝；`convertNode` 加深度上限（200）防栈溢出；读完立即关文件，不 mmap；LRU 同时按 chunk 数（128）和估算字节数限制。
7. **产品保留清单**：P0＝目录跳转(+目标闪烁高亮)、查找、复制、链接/相对路径图片、会话恢复+记住每个文件阅读位置、外部修改静默刷新保持位置、内容标记（迁移，见阶段 D）；P1＝拖拽打开、Ctrl+滚轮缩放、右键菜单、「用默认应用打开/在资源管理器中显示」（替代编辑入口）、导出/浏览器打开；可砍＝自动保存、编辑菜单、滚动同步、保存确认、新建文件（引导页文案改为「打开文件/文件夹」）。版本升至 2.0.0，CHANGELOG 明示「移除编辑功能」。
8. **查找语义**：候选 chunk（源文本命中）→ 渲染文本二次命中，无则跳过；命中数显示为「约 N 处」，扫描未完成前显示「≥N」。
9. **测试设计补充**：ChunkTable/锚点补偿做成纯逻辑类，注入测高回调与假度量，断言不变量（锚点屏幕 y 不变）；扫描器同步 `scanAll()`，线程仅薄封装；性能断言只做相对基线比值并打 `perf` 标签；一致性对比「块类型序列+纯文本+列表编号+链接 URL」，另加固定 seed 随机拼接模糊测试；覆盖 QA 提供的 14 类切块陷阱片段、UTF-8 边界/CRLF/BOM/空文件/无尾换行/超长行。
10. **旧测试处置**：删除 PieceTable/UndoStack/LineIndex/Document/Selection/MappedFile/SyntaxHighlighter/SearchWorker(编辑器)/ReloadDialog 等测试；改写 PreviewTocJump/CopyConsistency/Selection*/MarkingPersistence 为 chunk 版本。

### 第 2 轮（渲染 API 可行性 / 并发+滚动数学 / 拆除迁移）→ 设计 v3 修订
1. **渲染**：`layoutBlock` 无状态可复用；新增 `PreviewLayout::layoutChunk(docRoot,width,lineBase)` 返回 `{root,height,charLen,imageUrls}`（块间距 12px、首 chunk 顶部留白由 Viewer 负责）；新增 `PreviewPainter::paintChunk(...)`，每 chunk 重置字符计数与 `m_unorderedListDepth`，**选区/搜索/标记全部用 (chunk, 块内序号)**，不使用全局字符序号，彻底避免前缀长度依赖未布局 chunk；不使用 `placeholderPlainText`（与 `extractBlockText` 规则有偏差，属反模式 B），文本唯一事实来源 = `extractBlockText`（迁移为独立函数）。强切不切表格；硬上限 2 倍时才在任意行边界切。`ListItem` 里新建 `QFontMetricsF` 改走缓存。`imageReady(url)` → 仅失效含该 url 的 chunk。预热：窗口显示后/首屏前先 `updateMetrics(viewport)` 并预建 base/粗/斜/H1-H6/mono 全部字体变体与常见字符回退（实测定清单）。
2. **滚动数学**：Fenwick 用 int64；锚点单向写滚动条（`m_syncing` 屏蔽信号，setRange+setValue 同 guard，单帧最多 3 轮定点迭代）；拖滚动条期间冻结 scale 与校准系数；End = 跳转→精算末尾→二次锚定，末 chunk 精算前保留半屏缓冲；PageDown 在锚点 chunk 内计算；校准系数 EMA(α≈0.05)+死区、按 kind 分类、仅作用于锚点之下的未测 chunk；resize debounce 30–50ms，期间仅重排可视 chunk；scale 取 2 的幂离散档带迟滞；LRU 以像素/字节预算为准，不以 chunk 数。
3. **并发**：worker 不碰 ChunkTable，只产出不可变 `ChunkBatch`（shared_ptr<const>，含 gen），经队列连接交给 UI 线程独占的 ChunkTable；源缓冲 `QByteArray(size, Uninitialized)` 一次预分配，worker 渐进填充并以「水位线」发布，UI 只读水位线以下；批次按 ~60Hz 合并；generation 原子计数，取消不 `wait`（用 shared_ptr 状态让 worker 自行收尾，避免阻塞 UI）；同一路径复用 tab；重载锚点 = 源行号+行内偏移+64 字节指纹（行号→±N 行搜索指纹→比例兜底）；外部修改防抖 200ms 并校验 size 稳定；单行强切片降为 16KB。
4. **拆除顺序**（每步可编译）：①迁出 SearchBar（`sm_preview` 依赖 `sm_editor`）；②删保存/自动保存/显示模式；③`TabData.editor` 用途替换；④去 ScrollSync；⑤ViewerWidget 替换 PreviewWidget+ParseScheduler；⑥删 editor/core 编辑文件与测试，会话持久化改版。新 `TabData{viewer,filePath,openOrder,pending*}`；ViewerWidget 契约见代码。
5. **评审轮次安排**：R1（设计v1）、R2（设计v2）已完成；R3＝设计 v3 交互/测试计划评审（实现前）；R4＝实现后代码评审（扫描器/表/Viewer，cpp-reviewer）；R5＝集成后终审（性能实测数据 + 稳定性 + 产品验收）。
